# 2026-07-27 15:43 专业化重构

## 当前内容回顾

- 首版完成了独立部署与自动维护，但 UI 仍接近营销落地页：首屏大标题、卡片过大、信息密度低。
- 前沿信号只有事实/影响/边界短摘要，缺少技术机制、可比评分与下一观察点。
- 三条学习路线为空；已有课程只有四组短列表，没有先修、张量、伪代码、决策表或实验验收。

## 本轮计划

- 采用“70% 研究工作台 + 30% 系统课程”的产品方向。
- 重建前沿与课程数据模型，再重做首页、前沿、课程、课程详情和方法页。
- 使用失败测试锁定专业内容契约；使用桌面与移动截图做真实视觉审查。
- 不修改旧技术博客，不改变新站独立 URL 和双更边界。

## 实际执行

- 首页改为研究简报、信号看板、六研究域矩阵与四阶段能力路径。
- 前沿页改为可筛选信号矩阵，每条包含事实、机制、影响、证据边界、下一观察点和四维评分。
- 六个研究域全部补齐完整课程：MoE、CLIP、偏好对齐、LLM Serving、Agent harness、整体评测。
- 每节课程加入学习目标、先修、术语、心智模型、张量流、伪代码、决策表、动手实验、验收标准、自检和双来源。
- 方法页增加来源强度与结论可信度的区分，以及新颖性/影响/证据/复现四维评分定义。
- review 脚本新增评分覆盖、深度课程覆盖、直接引用数和路线 readiness。
