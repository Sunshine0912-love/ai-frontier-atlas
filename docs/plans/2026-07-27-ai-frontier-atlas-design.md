# AI Frontier Atlas 设计

## 定位

这是一个与既有技术博客完全独立的新网站、代码库和发布地址。网站服务两类需求：用高信噪比方式跟踪全球前沿 AI 进展；把关键 AI 技术组织为可连续学习的课程。前沿内容强调时间、原始来源、证据等级、影响和不确定性；学习内容强调概念地图、代码脉络、工程意义与自检问题。

## 信息架构

- `/`：编辑部式首页，展示最近前沿信号、今日判断、学习路线和维护状态。
- `/frontier/`：可扫描的前沿卡片流，按模型、系统、Agent、多模态、研究和产业分类。
- `/learn/`：六条系统路线与学习顺序。
- `/learn/[slug]/`：独立课程页。
- `/method/`：来源分级、事实/推断/判断边界和双更流程。

## 技术架构

使用 Astro 生成静态网站，内容存储在可审查的 JSON 数据文件中。页面构建时读取数据，因此无需数据库、账号系统或后端服务。Node 脚本在每次维护前生成站点回顾：内容数量、最近更新时间、类别覆盖、学习路线缺口和建议方向。GitHub Actions 将 `main` 分支部署到独立 GitHub Pages 项目。

## 双更维护

09:00 和 21:00 的自动任务必须先读取全站数据与最近维护日志，再运行回顾脚本并写本轮计划，之后才能编辑。09:00 侧重全球前沿信号；21:00 侧重技术连载与路线修订。来源或推导不足时不强行发布，以纠错、补源、结构维护或明确无更新代替低质量内容。
